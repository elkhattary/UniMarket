# UniMarket

Project Description:
E-commerce mobile app project for Mobile App Programming

Problem Statement:
Many users of e-commerce apps face issues such as:
- Fake sellers and scams
- Too many advertisements
- Complicated user interface
- Lack of trust in product reviews

Solution:
UniMarket aims to solve these problems by:
- Strong user authentication
- Verified sellers
- Trusted reviews
- Clean and simple interface

Features:
- User registration and login
- Product browsing
- Add to cart
- Seller product upload
- Secure authentication system
